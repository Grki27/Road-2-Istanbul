Calculation logic:

- Admin panel can see pending/approved/rejected comments.

Use environment variable:
OPENAI_API_KEY

Create a server-side moderation utility:
- moderateUserText(text, context)
- returns approved boolean and reason
- Use placeholder implementation if API key is not set.
- If no API key is set in development, allow safe dummy behavior but clearly comment it.

The moderation should block:
- Hate
- Slurs
- Threats
- Sexual content
- Doxxing
- Spam
- Scam links
- Extremely offensive messages

- noteColor

- status pending/approved/rejected

- Admin can delete notes.
- Admin can optionally reposition notes if that is easy.

- Same GPT moderation behavior as comments.
- New wall notes are pending first.
